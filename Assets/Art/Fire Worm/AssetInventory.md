# Fire Worm source inventory

Website: https://luizmelo.itch.io/fire-worm
License: CC0; original License.txt retained.

The user-supplied Fire Worm.zip contains Preview.png, License.txt and seven sprite sheets. Every source file matches the imported project file byte for byte.

- Worm/Idle.png: 9 frames
- Worm/Walk.png: 9 frames
- Worm/Attack.png: 16 frames
- Worm/Get Hit.png: 3 frames
- Worm/Death.png: 8 frames
- Fire Ball/Move.png: 6 frames
- Fire Ball/Explosion.png: 7 frames

There is no separate slam sheet in this archive or in the website's animation list. FireWormPresentation has separate editable Fireball Attack and Slam Attack arrays. Slam uses the first nine non-breathing attack poses plus a visual lift, lean, squash and seven-frame ground impact. This is a new presentation of existing artwork, not an additional source animation attributed to the pack. Body colliders remain stable throughout the motion.
